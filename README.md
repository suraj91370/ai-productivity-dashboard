> **ApexFlow AI** is a state-of-the-art cognitive productivity workspace engineered for high-performance software engineers, creators, and knowledge workers. It combines AI-driven workload prioritization, an interactive Deep Work Pomodoro hub with synthesized ambient soundscapes, a smart task matrix with autonomous subtask expansion, and focus telemetry.

---

## ✨ Features

- 🧠 **AI Cognitive Briefing & Copilot**
  - Instant workload analysis with peak cognitive hours tracking.
  - Interactive Copilot with one-click prompts for sprint breakdowns, 5-minute cognitive resets, and velocity summaries.
  - One-click **Auto-Prioritize Matrix** that reorganizes tasks by urgency and architectural weight.

- ⏱️ **Deep Work & Pomodoro Focus Hub**
  - Smooth animated SVG progress ring with glowing gradient indicators.
  - Modes: **Deep Work (25m)**, **Short Break (5m)**, and **Long Break (15m)**.
  - **Zero-Dependency Ambient Sound Synthesizer**: Generates white noise, cyber drone hums, and rain frequencies offline via the Web Audio API.
  - Celebratory confetti effects upon sprint completion.

- 🗂️ **Smart Task Matrix with AI Decomposition**
  - Multi-tier filtering (`All`, `Active`, `Critical`, `Completed`) and real-time search.
  - Categorization across Code, Architecture, Product, and Health domains.
  - **AI Autonomous Steps**: Expand any task into structured, actionable engineering phases.

- 📊 **Telemetry & Cognitive Insights**
  - Visual daily focus hours bar chart tracking Mon–Sun deep work blocks.
  - Domain focus allocation bars.

- 📝 **Scratchpad with AI Polish**
  - Live markdown-enabled notepad with instant "AI Polish" to structure notes into executive summaries and action checklists.

- 🚀 **GitHub Upload Hub**
  - Built-in interactive modal with pre-configured Git remotes and copy-paste terminal commands.

## 🚀 Quick Start

### 1. Clone & Install
```bash
# Clone the repository
git clone https://github.com/suraj913708/ai-productivity-dashboard.git
cd ai-productivity-dashboard

# Install dependencies
npm install
```

### 2. Run the Development Server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 3. Build for Production
```bash
npm run build
```
